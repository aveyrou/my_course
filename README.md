# AveyRouTe — веб-приложение для поиска и планирования туристических маршрутов

Учебный проект (курсовая работа, 2 курс, направление «Программная инженерия»). Простое веб-приложение на ASP.NET Core 10 (MVC) с EF Core + SQLite и современным интерфейсом на Bootstrap 5 с авторскими стилями.

## Возможности

- Главная страница с поиском, статистикой и подборкой популярных маршрутов
- Каталог маршрутов с фильтрами: страна, город, тип, длительность, цена
- Подробная страница маршрута: описание, список достопримечательностей по дням, отзывы и рейтинг
- Форма отправки отзыва (валидация на сервере) + удаление отзыва
- Планировщик поездок: создание плана, список «Мои поездки», удаление
- Страница «О проекте»

## Технологии

- **ASP.NET Core 10** (MVC)
- **Entity Framework Core 10** + **SQLite** (база создаётся автоматически при первом запуске и сидится тестовыми данными)
- **Bootstrap 5** + собственный CSS (`wwwroot/css/site.css`)
- **Razor Views** для отображения

## Как запустить

Требуется **.NET 10 SDK**: https://dotnet.microsoft.com/download

```bash
cd TouristRoutes
dotnet restore
dotnet run
```

Приложение поднимется на `http://localhost:5050` (порт настраивается в `Properties/launchSettings.json`).

При первом запуске будет создан файл `tourist_routes.db` (SQLite) и заполнен 11 готовыми маршрутами с достопримечательностями и отзывами.
